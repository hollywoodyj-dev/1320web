## 1. 本轮目标

将已确认的 v0.2.3 产品结构转化为一致、沉浸、移动端优先的视觉体验，同时保持原型的隐私、治理和叙事边界。

本轮只允许：

1. 接入视觉层级、版式、图腾资产与状态样式。
2. 优化移动端可读性、点击范围、滚动与安全区。
3. 优化既有动效的连贯性和减少动效模式。
4. 修复不改变产品规则的轻量 UI 反馈问题。

本轮不允许：

- 改写 1320 结构、四境顺序或固定蓝图逻辑。
- 将占位图腾描述为官方 1320 图腾。
- 接入真实算法、账号、支付、服务器或多人星墙。
- 加入网络请求、浏览器存储、第三方分析或追踪。
- 将 v0.2.3 标记为冻结版。
- 进入 Preview 或 Production。

## 3. 视觉方向

### 3.1 核心气质

关键词：

- 深夜梦境
- 安静召唤
- 神秘但不神化
- 温柔但不幼态
- 仪式感但不制造权威
- 有灵魂感但不暗示超自然事实

避免：

- 游戏化积分、等级、奖励爆炸或强烈胜负反馈。
- 霓虹赛博朋克、过亮紫色、过度粒子特效。
- 塔罗牌、宗教法器或已有文化体系的挪用感。
- 把“完成”表达成灵性升级、疗愈成功或频率提高。

### 3.2 主色系统

```css
:root {
  --ink: #070d24;
  --deep: #0f1b45;
  --dusk: #1b2a63;
  --gold: #f0c97a;
  --gold-d: #c99a45;
  --moon: #e8ecfb;
  --mist: #a9b4dc;
  --line: rgba(159,171,214,.30);
  --glow: rgba(240,201,122,.22);
  --danger: #ffb4a8;
}
```

使用原则：

- `--gold`：主行动、已显影状态、关键数字和生命灯。
- `--gold-d`：边框、路径、辅助分隔，不作为大面积背景。
- `--moon`：正文与高优先级信息。
- `--mist`：解释、状态、非主行动。
- `--danger`：仅用于明确输入错误。

### 3.3 字体与层级

- 中文标题：Noto Serif SC / Source Han Serif SC / Songti SC 回退。
- 正文与控件：PingFang SC / Noto Sans SC / Microsoft YaHei 回退。
- 正文不得小于 16px。
- 辅助说明建议 14px，但颜色对比必须通过移动端肉眼检查。
- 主标题 34px；场景标题 25px；卡片标题 18px。
- 英文标签使用轻微字距，不使用全屏大写装饰文案压过中文叙事。

### 4.2 状态

**沉睡状态**

- 线条：`--mist`
- 透明度：约 `.7`
- 虚线：`stroke-dasharray: 2 3`
- 不使用金色发光

**显影状态**

- 线条：`--gold`
- 实线
- 允许轻微金色光晕
- 不放大到压过场景名称

### 4.3 语义边界

- 图腾只代表该境是否已走过。
- 图腾状态不参与出生日期算法。
- 图腾不改变固定蓝图。
- 不使用“觉醒等级”“频率提升”“能量解锁”等表述。
- 保留“示例占位／非官方图腾”的明确说明。

### 4.4 建议显示位置

- 四境地图：四个图腾并列，作为旅程进度的辅助表达。
- 单一场景顶部：显示当前境图腾及沉睡／显影状态。
- 简版蓝图：30px 左右，作为领域识别标记，不作为蓝图结果本身。
- 生命灯：继续以四块光表示完成度，不把图腾直接塞入灯内。

## 5. 关键组件

### 5.1 主按钮

- 高度不低于 48px。
- 金色实心只用于页面当前唯一主行动。
- 次行动使用透明背景加细边框。
- “暂时离开”“跳过”使用链接式按钮，但点击范围仍须不低于 44px。
- 禁用状态保留可读文字，透明度约 `.4`。

### 5.2 选择项

- 全宽卡片。
- 左侧金色细线提供方向感。
- 选中状态采用金色边框及轻微金色底色。
- 安静／跳过类选项降低视觉权重，但不可降低可读性。

### 5.3 信息卡

- 固定蓝图使用金色边框，突出其与“今日选择”的结构差异。
- 今日探索记录使用普通边框。
- 两者不可通过同一种高亮表现，避免用户误解选择会重算蓝图。

### 5.4 表单

- 输入高度不低于 48px。
- iOS 下正文和输入字体不得低于 16px，避免自动缩放。
- 错误信息紧邻相关表单区，使用 `role="alert"`。
- 输入有效内容后，应即时清除旧的空瓶错误提示。

建议补丁：

```js
if(k==='exp'||k==='ins'||k==='wish'||k==='cwText'){
  S.bottle[k]=el.value;
  if((k==='exp'||k==='ins'||k==='wish')&&S.bottle.err){
    S.bottle.err='';
    const e=$('#berr');
    if(e)e.textContent='';
  }
}
```

该补丁只改善反馈，不改变封存规则。

## 6. 逐屏视觉要求

### 6.1 序幕

- 旅人为主视觉焦点，标题与两段梦境文字依次出现。
- 动效节奏宁慢勿急；不得加入倒计时。
- “进入梦境”为唯一主行动。

### 6.2 接住四颗光

- 四颗光必须有足够点击范围，数字清晰。
- 用户点击顺序不影响最终 1320 排列。
- 光消失与槽位显现应连贯，不使用奖励爆炸。

### 6.3 门前觉察与密码门

- 三问页面保持低压，不将“先不回答”弱化到难以发现。
- 门的视觉应体现邀请与未知，而非安全验证。
- 密码说明必须持续写明“故事里的仪式，不是安全密码”。

### 6.4 蓝图钥匙

- 隐私说明必须在日期控件前可见。
- 年月日三列在 390px 宽屏幕仍能完整点击。
- 示例日期入口明确为次行动。

### 6.5 四境地图

- 1→3→2→0 路径清晰，但不暗示必须按该顺序探索。
- 每个节点最小点击范围 44×44px，推荐 58×58px 以上。
- 旅人、节点名称和“已走过”状态不得互相遮挡。
- 图腾进度区位于地图下方，不与节点重复争夺注意力。
- “让地图带路”是辅助选择，不制造随机奖励感。

### 6.6 四境场景

- 场景标题、编号和图腾形成统一顶部结构。
- S1 意象按钮保持两列；小屏时文字不得贴边。
- S3 波形画布不得抢过操作文案；滑杆状态同步更新无障碍标签。
- S2 关系主题不显示或要求他人姓名。
- S0 呼吸圆保持柔和；跳过呼吸始终可见。

### 6.7 简版蓝图

- “A. 固定蓝图”与“B. 今日探索记录”必须视觉分层。
- 示例标签始终可见。
- 出生日期属于私人蓝图钥匙，不进入导出卡和公开星愿。
- Full Report 区不得出现虚构价格或结算入口。

### 6.8 星愿瓶

- 首屏帮助文案必须保持：经历、领悟和留给读者的话至少填写一项。
- 三个主要内容字段视觉权重一致。
- 蓝图片段与内容提示是附加项，不得表现成可单独封存的主体。
- 空瓶错误清楚但不责备用户。
- “不放了，直接去星墙”保持可见，体现用户主权。

### 6.9 公开预览

- 公开内容与不会公开的内容必须形成清楚区块。
- 同意框默认不勾选。
- 更换公开代号后自动撤销同意。
- “只留给自己”与“点亮生命流星”必须明显区分。

### 6.10 生命流星

- 动画表达“分享一道光，而不是失去自己的光”。
- 必须保留跳过动画。
- 减少动效模式直接进入完成状态。

### 6.11 星墙

- 星星没有大小排名或热度排序。
- 用户自己的星用金色识别；示例星明确标注为示例。
- 内容提示先于敏感内容展示。
- 回响动作不得使用评论框、建议或诊断语言。

### 6.12 说明弹层

- 保持底部 sheet 形式。
- 锁定焦点；Esc 可关闭；关闭后焦点返回触发按钮。
- 长内容可以滚动，底部关闭按钮不能被安全区遮挡。

## 7. 动效与声音

### 7.1 动效原则

- 动效用于方向、状态和叙事，不用于奖励刺激。
- 页面淡入：约 500ms。
- 地图移动：约 1.2–1.5s。
- 门开启：约 1.3s。
- 光汇入灯：约 1.2–1.6s。
- 生命流星完整动画：约 6s，并可跳过。

### 7.2 减少动效

`prefers-reduced-motion: reduce` 下：

- 取消循环动画和位移动画。
- 不延迟核心操作结果。
- 呼吸练习仍需由用户主动开始，但视觉不缩放。
- 流星直接显示完成状态。

### 7.3 声音

- 默认关闭。
- 无持续背景音乐。
- 只保留轻量原创合成音：灯亮、脚步、回响、升空。
- 未开启声音时不创建持续音频状态。

## 8. 移动端与安全区

### 8.1 必测设备与视口

- 390×844
- 430×932
- 1280×800
- iPhone 真机 Safari，包含刘海／Dynamic Island 与底部 Home Indicator
- 至少一台 Android 真机 Chrome

### 8.2 安全区要求

- 顶部栏不得贴入状态栏或 Dynamic Island。
- 页面底部主按钮、关闭按钮、星墙操作不得落入 Home Indicator。
- 使用：

```css
padding-top: env(safe-area-inset-top);
padding-bottom: env(safe-area-inset-bottom);
```

- 弹层底部额外保留 `24px + env(safe-area-inset-bottom)`。

### 8.3 真机重点

- 地图四节点点击是否准确。
- 右侧 S0/S2 节点是否接近屏幕边缘。
- 日期选择器是否触发 iOS 原生控件并可完成选择。
- 键盘弹出后星愿瓶错误信息和按钮是否可见。
- 公开预览与星墙长内容滚动是否顺畅。
- modal 焦点与页面滚动是否冲突。
- “保存私人卡”下载在 Safari 中的行为及截图替代提示。

## 9. 无障碍要求

- 所有可点击元素可通过键盘访问。
- 焦点轮廓必须清晰可见。
- 纯装饰星点、远处人形与装饰 SVG 使用 `aria-hidden="true"`。
- 旅人 SVG 保留描述性 `aria-label`。
- 密码输入进度、流星字幕和地图完成提示使用适当 live region。
- 颜色不是唯一状态信号：图腾以虚线／实线辅助区分。
- 触控目标不低于 44×44px。

## 10. 封存规则锁

进入公开预览或私人封存前，以下三项至少一项经 `trim()` 后非空：

- `experience`
- `insight`
- `wish`

以下内容不构成可单独封存的星愿：

- 蓝图片段
- 内容提示
- 公开代号

允许用户完全不封存并直接进入星墙。

公开 payload 必须恰好保留六个白名单字段：

```text
alias
experience
insight
wish
blueprintSnippet
contentWarning
```

不得序列化整个状态对象。
