## 2｜要從這四份報告學到什麼？

1. **不動結構，只潤飾文字。** 每碼仍有完整的七段：定義／作用與核心價值／力量／張力與人生課題／兩個假設生活例子／領悟／反思。各節標題、順序與功能不取消。
2. **讀起來像一份有價值的生命藍圖。** 定義說得清楚，能自然接上生活例子，有啟發但不誇張、不宣稱知道讀者經歷。
3. **兩個生日的內容明顯不同。** 1980 重心是轉化、探索、價值、自我要求、結構與臨在；1982 重心是感受、投射、情緒、保護、自我信任與誠實。不能只換稱呼或 Code 標籤。
4. **整合有自己的論述。** Full 的第 07、14 章不是重貼前幾章，而是回答這組具體 Code 如何彼此互補；同時不把跨碼呼應當成心理或靈性證明。
5. **Free Sample 自身完整。** 不加入 S4～S9 內容，也不使用「你不購買就無法完整理解自己」的壓力話術。
6. **Full 有真正的新增閱讀價值。** S4～S9 各自有明確定義和生活解釋，第 14～17 章使讀者能把理解帶回日常。

- `REPORT_NARRATIVES_RC3_CANDIDATE_INTERNAL.json` 包含 20 筆候選的七段內容及來源段落 SHA-256；**供內部編輯／工程追溯，不是顧客版生產 API**。
