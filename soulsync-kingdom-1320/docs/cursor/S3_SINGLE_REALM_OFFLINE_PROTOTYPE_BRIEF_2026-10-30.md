## 1. 请批什么

批准做一个 **独立的、离线的、中文的 S3 振动之海短体验**，用来回答三个问题，而不是实现整份 lead magnet 提案。

| 样机要观察的 | 不是本轮目标 |
|---|---|
| 玩家是否知道自己可以做什么 | 开场 / 接光 / 1320 门改造 |
| 是否能区分今夜节奏与固定蓝图 | 门 1 / 门 2 分流、留资渠道 |
| 是否愿意保存今夜卡或继续探索 | 四境、官方图腾、Adapter、英文版 |

最有价值的两项（玄微）：**让场景承担互动**，以及 **完成一境就能带走今夜卡**。

---

## 2. 玩家走过什么

无生日。短体验本身完整。

```text
进入振动之海（短说明：这不是测试；没有对错；本段不生成 1320 蓝图）
  → 海面可划、可调；世界会回话
  → 可「停一会儿」（背景动作减弱，节奏值不变）
  → 可跳过、可留白、可完成
  → 波纹中显影：境域占位符号（标明占位，不是官方图腾）
  → 并列一屏：今夜节奏  |  固定蓝图尚未生成
  → 今夜卡：选择摘要；自由文字默认不进卡
  → 邀请：保存卡片 / 了解如何生成私人蓝图 / 结束
```

「了解如何生成私人蓝图」在样机里是 **说明页**，不调用 `Adapter1320.compute()`，不展示 DEMO 编号，不假装官方结果。说明：私人蓝图需要生日钥匙和正式 1320；本样机只保留今夜节奏。

## 3. 必须遵守

- 新文件名，从 `src/current/soulsync-kingdom-1320-v0.2.3-visual-dev.html` **复制**，不覆盖原件，不改冻结 v0.2.2，不改 Adapter。
- 零网络；无 `localStorage` / `sessionStorage` / cookie。
- 先中文；保留 `EN` 键位，不验收英文。
- S3 选择语义与现有四档节奏文案一致；不是频率测量、不是等级。
- **停一会儿 ≠ 改节奏。** 背景可静，最终节奏值仍是玩家上次主动选定的值。
- 今夜卡默认：境名、节奏摘要、占位符号、来源条「今夜记录，尚未生成私人蓝图」。不出现生日。
- 自由文字须勾选并预览才进导出图。私人卡导出 ≠ 星墙六键 payload。
- 不接线 `assets/official-1320-fixture/` 四枚 WebP。
- 减少动态模式可走完全程。
- 不收集名单。

## 4. 怎么知道样机有没有用

几位目标用户旁观即可，不接分析 SDK。

看他们会不会：不靠人教就去划海；能指着并列屏说出「这边是今晚、那边还没有蓝图」；主动点保存或「了解蓝图」。  
不把完成率、15 秒留存、四境转化当成本轮成败。
