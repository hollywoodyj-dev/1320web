WHAT IS 1320?

一套關於自我理解的
象徵性生命藍圖

1320 是以生命藍圖為核心的反思系統。它將生日視為一個象徵性的入口， 讓我們從不同角度理解自己的表達方式、人際互動、價值與選擇。

這套語言不定義你是誰，更不替你預言未來。它希望提供的是一份可以慢慢閱讀、對照生活， 也能自由質疑的理解空間。

英文官網 FAQ
1320 是占卜或命運預測嗎？

不是。1320 使用生日作為象徵性閱讀入口，協助人從不同視角反思生活，並不預測事件或決定性格。

Free Sample 與 Full Report 有什麼差別？

Sample 以 S1、S3、S2、S0 四碼為完整起點；Full 進一步展開 S4～S9，並保留十碼整合、七日練習與反思日誌，共 17 章。

需要提供出生時間或地點嗎？

按照目前英文官網的說明，1320 使用出生年月日作為計算輸入，不需出生時間或地點。

為什麼此設計原型不能直接購買？

這是 NOVA 內部 UI 設計及工程對齊版本。正式產品的內容審核、帳號權限、定價、付款和地區條款須由產品負責人另行確認。
