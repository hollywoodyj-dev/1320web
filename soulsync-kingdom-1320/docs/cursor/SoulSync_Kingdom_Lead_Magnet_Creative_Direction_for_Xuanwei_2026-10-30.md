## 0. 请先读的三句话

1. **磁铁是一份完整的礼物，不是一份残缺的测试。** 年轻人最熟的「先玩两分钟、留资看结果」会把 1320 做成又一个 MBTI，也会把 Kingdom 做成漏斗。这与 GDD §20（免费旅程完整、Full Report 不是补结局）直接冲突。
2. **加乘发生在「固定蓝图 × 今夜回应」的并列里，不发生在把报告做成动画、也不发生在用玩家选择重算编号。**
3. **个性化 1320 蓝图不能用 DEMO 编号对外冒充。** 无生日的短体验可以本身完整（今夜记录 + 境域符号），不依赖全量 126 枚图腾；**只有宣称生成个性化 1320 蓝图的路径**才依赖正式算法。用假身份换名单，正式结果一对不上，两个品牌一起失信。

### 0.1 玄微裁定（2026-10-30）— 实现前四处修正

1. **S3 记录必须忠实。** 「停一会儿」可以减弱背景动作，但**不得改写玩家选定的最终节奏值**。若要改变节奏，须由玩家主动选择（滑杆 / 划水 / 快慢按钮）。
2. **今夜卡默认不带私人自由文字。** 默认只展示选择摘要（节奏档等）。玩家明确勾选并预览后，才把自己写的话加入导出图。私人卡导出与星墙六键 payload 分别处理。
3. **短体验本身应完整。** 无生日的一境可以成为独立体验，前提是说清内容、完成必要测试、取得发布授权。获客体验不必等待全量图腾。
4. **市场判断先当假设。** 「前 15 秒必须怎样」「中文年轻人偏好什么渠道」「走完四境才是合格 lead」均待验证。短体验后愿意保存、继续或了解 1320 的人，同样可能有价值。

样机只回答三个问题：玩家是否知道自己可以做什么、是否能区分今夜节奏与固定蓝图、是否愿意保存卡片或继续探索。

## 1. 产品判断

### 1.1 一句话

1320 是玩家带不走的结构；Kingdom 是玩家今晚怎么遇见它。Lead 是「刚在一个地方留下过脚印、还想回同一扇门」的人，不是「想拿一张人格标签」的人。

### 1.2 两个产品各自负责什么

| | 1320 SoulCode | SoulSync Kingdom |
|---|---|---|
| 本质 | 由出生日期 + 官方算法生成的固定蓝图 | 一次不被评判的梦境旅程 |
| 玩家记住的 | 1-3-2-0；四枚图腾；这是我的地图 | 我在林/海/岸/门里做过什么；我的光没有因分享而减少 |
| 可变吗 | 不可被场景选择、访问顺序、是否付费改写 | 今夜的意象、节奏、距离、留白可以变 |
| 若单独存在 | 读完容易忘（GDD §3.1） | 一次好看的散步，缺少「这是我的王国」 |
| 加乘后 | 报告变成可走进去的世界 | 散步变成可回访的私人神话 |

### 1.3 年轻人市场对这条判断的压力

目标玩家与 GDD §3 一致：喜欢占卜 / 卡牌 / 数字系统，但厌倦被分类；要仪式感和可收藏结果；愿意分享一句，不愿交出身份。

年轻冷流量可能带来四件事（**下列为待验证假设，不是样机成功标准**）：

- 前 15 秒更像世界、更不像须知，冷启动留存可能更高。现在开场是说明 + 按钮。
- 有可带走、可截的东西（且不含生日）可能提高「留下」意愿。现在导出卡偏报告。
- 留资若发生在礼物已经在手上之后，名单质量可能更高。
- 中文年轻人的捕获口可能不是默认邮箱。EN 文案目前是空占位。

样机阶段不验证渠道，只观察：知不知道能做什么、分不得分清今夜与蓝图、愿不愿意保存或继续。

### 1.4 成功时玩家离开应带走的

不是「我是哪一种人」，而是：

1. 我接住过 1320。
2. 我走进过至少一个会回话的地方。
3. 固定的那一枚图腾，和我今晚选的东西，被放在一起，没有谁吃掉谁。
4. 我手里有一张不含生日的今夜卡。
5. 同一扇门还可以再开（官方显影 / 四境走完 / Full Report 内室）。

若玩家只记住一份测试结果，GDD §24 判定设计尚未成立——做 lead magnet 时这条仍然成立，而且更严：测完就走的人，不是 1320 要的名单。

## 3. 当前原型的体验诊断（相对 GDD，不是相对「更花哨」）

GDD §2.3：界面不是连续问卷；问题通过场景、动作与视觉回应出现。  
GDD §16.2：上方约 70% 世界，下方约 30% 面板。

v0.2.3 visual-dev 的骨架是对的（序幕 → 接光 → 门前 → 1320 门 → 生日钥匙 → 四境 → 简版蓝图 → 星愿 → 流星 → 星墙），气质也已经是深夜梦境。问题是 **世界还没有承担问题**，问题仍在选项、滑杆、输入框上：

| 屏 | 现在实际是 | GDD 要的 | 对年轻人 magnet 的伤害 |
|---|---|---|---|
| 序幕 | 说明 + 两个按钮 | 好奇，不是神秘压迫 | 冷流量前 15 秒像须知 |
| 接光 | 点四个漂浮数字，格子亮起 | 数字成为可记忆入口 | 还行，但光没有「飞进」1320 |
| 门前三问 | 三页选项 | 抵达当下，可跳过 | 像问卷；冷启动应可整段跳 |
| 密码门 | 数字垫 | 仪式 | 结构在，门与数字的关系还可以更身体 |
| 生日 | 三个下拉 | 私人钥匙，不是交身份 | 高摩擦 + 高隐私，且出现得偏早、偏表单 |
| 地图 | 四个节点 + 旅人位移 | 空间导航 + 灯 + 图腾 | 可保留；进场景仍像传送 |
| S1 | 2×3 词按钮 | 林、根、六个意象 | 最像测试 |
| S3 | range + canvas | 调水面、停一会儿 | 身体感最接近，仍是控件 |
| S2 | 关系列表 | 两团倒影与距离 | 没有「靠近 / 设距离」的空间 |
| S0 | 小圆呼吸圈 | 灯留门外、虚空胀缩 | 姿势代码已有，场景未用满 |
| 显影 | 角落徽章变实线 | 从图腾所在的环境里看见 | 1320 没有「遇见」这一拍 |
| 蓝图 | A / B 两张卡片上下堆 | 结构与今夜痕迹并列、互不改写 | 报告感；不是可截的礼物 |
| 流星 | 一段 Canvas | 五拍品牌高潮 | 记忆点偏弱 |
| 星墙 | 本机样例星 | 共同夜空，有限回响 | 可转性弱，且不能当社交 Feed |

结论：不必重做世界观。要改的是 **谁在画面中央**（世界 vs 表单）、**1320 何时被看见**（开场摊牌 vs 完成一境才显影）、**礼物何时交到手上**（报告页 vs 一境结束后的今夜卡）。

## 4. 建议的体验模型

### 4.1 三条环，不要一条问卷

```text
环 A  固定蓝图（1320）     一次生成，恒定，官方图腾
环 B  今夜旅程（Kingdom）   可重复，探索记录，不改 A
环 C  内室（Full Report）   同一图腾的更深房间 / 已制作的后续地图
                              不是补完环 B
```

磁铁可以先卖 **环 B 的一次完整遇见**（S3 单境即可自成礼物）。环 A 在玩家愿意给出生日钥匙、且正式算法可用时才出现。环 C 只对已经遇见过的人说话。走完四境仍是完整免费层，但**不是**「合格 lead」的唯一定义：短体验后愿意保存、继续或了解 1320 的人同样可能有价值。

### 4.2 核心玩法：并列，不混算

每境结束只做一件事：把官方这一侧和今天这一侧并排放着，系统不宣布它们是否「符合」。

**映照允许（与 GDD §15.2 一致）：**

- 今天你靠近的是种子。
- 你停在缓慢的潮。
- 你为这段关系设了一段距离。
- 你的固定蓝图里，有一枚刚刚从沉睡里显影的图腾。
- 它们是否同一种感觉，由你决定。

**映照禁止（与 GDD §15.3 一致）：**

- 因为你是 Transformer，所以你该选火。
- 你的 S3 说明你频率偏低。
- 这证明你有某种依恋 / 创伤。

DEMO 阶段也必须这样写。示例数据可以并列，但必须持续标注「示例数据，非 1320 原始算法」。正式接入后，同一骨架换成官方 `code / name / shortMeaning / totem`，文案结构不变。

### 4.3 遇见，不要开场发报告

生日提交（或正式 Nova 返回）只生成钥匙，**不在出生屏摊开四张官方卡**。

| 时刻 | 玩家看见 |
|---|---|
| 钥匙生成后 | 四境地图；图腾在环境里是沉睡轮廓 |
| 完成某一境（无生日） | 境域占位符号可在环境中显影；只展示今夜记录；邀请生成私人蓝图，不摊开编号 |
| 完成某一境（已有正式蓝图） | 该境官方图腾从环境显影；短名可选、视觉次于玩家选择摘要 |
| 四境聚齐 | 简版蓝图：A 区四枚已显影官方结果 + B 区四条今夜痕迹 |
| Full Report | 同一枚图腾后面的内室；未制作地图只标「规划中」 |

「完成场景 = 看见，不是升级」——GDD §9.2 已写。本提案只是要求 **看见发生在世界里**，而不是发生在徽章上。

灯的四区与图腾显影仍只表示走过几境，不表示等级、频率、疗愈程度。

## 5. Lead magnet 漏斗（年轻人冷流量）

### 5.1 两条门，不要一堵 12 分钟的墙

```text
竖屏钩子（约 15–90 秒，可静音看懂）
   接四颗光 → 排成 1320 → 门缝透金 → 进入一个会动的世界
        │
        ├─ 门 1「今晚先走一境」   ← 获客磁铁
        │     一境完整：动作 → 世界回应 → 显影 → 并列映照 → 今夜卡
        │     然后邀请：走完四境 / 留下同一扇门 / 看内室（若已存在）
        │
        └─ 门 2「四境完整旅程」   ← 合格 lead
              8–12 分钟，GDD 免费层全部交付
              完整免费层；是否「更合格」待验证，不是样机成功门槛
```

系统 **不得** 用 1320 编号替玩家决定走哪一境。单境样机固定 **S3 振动之海**。未来正式入口提供自选与随机带路（已有 `guide`），不是算法人格。

门 1 走完仍是一次完整礼物：有遇见、有卡片、有跳过权。它不是四境的残缺试玩，而是「今晚只走一间房」。四境仍在，门仍开。

### 5.2 礼物、请求、分享必须拆开

| 层 | 玩家得到 / 做的 | 同意 |
|---|---|---|
| 礼物 | 今夜卡（竖屏）：境名 + 已标明的境域占位（或日后可选官方短名）+ **选择摘要**；自由文字默认不进卡 | 不需要留资 |
| 请求（lead） | 出卡后邀请继续探索或生成私人蓝图 | 样机只观察意愿，不上渠道；渠道由后续用户测试定 |
| 分享（可选） | 竖屏镜头（接光、点灯、流星）或今夜卡或星愿一句 | 与 lead 拆开；永不含生日、完整蓝图、门前回答 |

**禁止：** 结果前弹表单；不勾同意就灰掉「看我的图腾」；用倒计时催留资。

### 5.3 留资话术（方向，不是最终文案）

允许的意思：

- 这张卡你可以先拿走。
- 同一扇门还可以再开。
- 若你愿意，我们只在你选的渠道告诉你：官方图腾已在你的境里显影，或内室已可进入。
- 出生日期不会出现在这条消息里。

不允许的意思：

- 留下联系方式才能看结果。
- 你的灵魂编号马上过期。
- 和与你蓝图相同的人匹配。

### 5.4 生日在漏斗里的位置（已裁定）

**可以先体验、出今夜卡，再邀请生成私人蓝图。** 未输入日期时，只展示今夜记录与境域符号，不出现官方短名、不出现 DEMO 编号冒充 1320。

四把钥匙仪式 **暂缓**。若玩家之后愿意生成蓝图，仍用 **一把生日钥匙**（年-月-日），降低理解成本。提交瞬间不摊开四张官方卡。

钥匙默认只在当次会话。写入账号 / CRM 必须另一次同意，且联系方式与生日拆开。公开六键与星墙继续禁止生日。本机样机继续零持久化、零网络。

## 6. 逐屏改动清单

下列「改」都指 **新文件名上的体验**，不覆盖现文件。每一项都标了：是否依赖官方资产、是否可在 DEMO 上先做。

### 6.1 竖屏钩子 / 序幕

**改：** 前 15 秒以旅人、微光、门为主；说明改成短句或可后置的「说明」。免责声明仍要有，但不能占满首屏。  
**可 DEMO 先做。**  
**文案原则：** 这不是测试。没有对错。首轮可停。

### 6.2 接住四颗光

**改：** 光点飞入 1-3-2-0 空位，而不是格子突然亮。顺序仍不改变最终排列。  
**可 DEMO 先做。**  
**magnet：** 这一段必须能截成竖屏静音视频。

### 6.3 门前三问

**改：** 冷启动（门 1）允许整段跳过，不只是每问「先不回答」。完整旅程（门 2）保持现逻辑：三问可逐题跳，回答不进蓝图。  
**可 DEMO 先做。**

### 6.4 1320 之门

**改：** 每输入一位，门从内往外透金；正确四位开启。两次错误后的清晰提示保留。  
**可 DEMO 先做。**  
1320 仍是故事仪式，不是安全凭据。

### 6.5 蓝图钥匙（生日）

**改：** 单境样机不收生日。完整路径仍用一把生日钥匙，减少档案表感即可。四把钥匙仪式暂缓，避免被读成公式。  
宣称个性化 1320 时必须走正式算法；样机若演示钥匙形态，须标 DEMO，且不得把 DEMO 编号写成官方结果。

### 6.6 四境地图

**保留** 自由访问、结构顺序 S1→S3→S2→S0、带路、文字地图。  
**改：** 旅人沿星线走动（位移已有，进场景不要瞬间传送）；完成返回时的点灯停 2–3 秒；图腾行可保留为摘要，但**第一次显影必须发生在场景内**。  
**门 1：** 地图可缩成「今晚这一境」+「四境仍在」的出口，避免冷流量被四节点吓成任务清单。

### 6.7 四境（空间化，选择集合不变）

选择、跳过、留白、不认同的**语义集合不变**（Data Pack §6）。变的是它们发生在世界上。

#### S1 原型之林

六个意象仍是：灯、种子、河、山、门、火。它们是场景素材，不是官方 S1。  
**改：** 林中可点的物件，选中者微亮、根系呼吸，其余变淡不消失。改名是「我的说法」，刻在物件旁，不覆盖官方名。  
完成 → 树纹中图腾显影 → 并列：今夜意象 vs 该境固定结果。

#### S3 振动之海（样机主场）

滑杆 / 划水语义保留为当下节奏，不是 S3 等级。四档描述保留。  
**改：** 手指可划水面，世界承担互动。**「在这里停一会儿」只减弱背景动作，不改写最终节奏值。** 若要改变节奏，玩家必须主动再划 / 再拖 / 再按快慢。声音仍默认可关，且不是频率治疗。  
无生日：完成 → 波纹中境域占位显影（标明占位）→ 并列：今夜节奏 vs 「固定蓝图尚未生成」。  
有正式蓝图后：并列今夜节奏 vs 该境官方结果（短名可选、小于选择摘要）。

#### S2 镜像之岸

关系主题与动作集合不变。「暂时不选」仍直接进入映照。  
**改：** 两团倒影；靠近 / 设距离 / 只看，改变间距。系统只描述玩家这一侧。  
完成 → 倒影交叠处显影 → 并列。

#### S0 空性之门

呼吸可跳过；放下词 / 带走 / 不急着回答 / 返回地图均保留。  
**改：** 旅人把灯留在门外（`release` 姿势已存在）；呼吸是虚空胀缩；词化为微尘或浅刻在灯上。禁止净化 / 业力 / 疗愈完成等功效性文字。  
完成 → 门后负空间显影 → 并列。

四境均可 DEMO 先做空间与并列骨架；官方图腾未到时，显影用**已标明的境域占位符号**，不得用占位冒充某编号。

### 6.8 点灯与显影（品牌拍）

完成一境：世界静两秒 → 灯的对应区亮起 → 图腾从环境显影（一次，不循环闪）→ 并列映照 → 今夜卡。  
减少动态模式：取消动画，直接完成态（已有 `prefers-reduced-motion`）。

### 6.9 今夜卡（新礼物层，magnet 核心交付物）

**新屏或可下载的竖屏卡，一境结束后即可生成**，不必等四境。

正面默认只含：

- SoulSync Kingdom / 1320 作为门，不作为测试 Logo 墙
- 境名（振动之海）
- 境域占位符号 + 明确标注（样机）；正式接入后官方图可选，短名可选且视觉次于选择摘要
- **选择摘要**（S3：节奏档文案）。自由文字默认不进卡
- 来源条：无生日时写清「今夜记录，尚未生成私人蓝图」；有正式结果时写 `官方 1320`；DEMO 计算若出现则必须写 `示例数据，非 1320 原始算法`
- 不出现生日、不出现完整四枚编号墙、不出现门前回答

玩家须 **明确勾选并预览** 后，才把自己写的话加入导出图。该导出是私人卡，与星墙六键 payload 分开，不得把私人留言自动拷进公开字段。

四境走完后，可另出一张「四境简版」私人卡（现有 `exportCard()` 的进化，而不是再做一张报告）。现有导出已含 DEMO 标注，应保留并改构图。

### 6.10 简版蓝图

A / B 分离保留。  
**改：** 不要做成两份问卷摘要上下堆。视觉上是同一夜空：A 是四枚已显影图腾（结构），B 是叠在旁边的今夜脚印。固定声明保留：

> 蓝图是象征性探索底座；今天的选择是你此刻留下的痕迹。两者互不改写，如何理解仍由你决定。

Full Report 入口：只显示真实状态，不写假价格、不模拟支付（GDD §11.3）。对 magnet 的措辞是「内室」，不是「解锁完整你」。

### 6.11 星愿瓶 / 公开预览 / 流星 / 星墙

瓶的三项至少填一、独立同意、六键白名单、永不自动公开——**不改规则**。  
**改：**

- 流星做成可跳过的五拍：托瓶 → 光入瓶 → 灯仍亮 → 升空 → 落入星墙。文案保留：「你没有交出自己的光。你只是让它，也照到别处。」
- 星墙点星时光圈一扩；回响只改变温度，不出现数字。远处旅人可偶尔走动（`far()` 已有）。
- 分享星愿与留资拆开。

门 1（只走一境）**可以**先给今夜卡、不强迫进瓶；瓶仍属于完整旅程的高潮，不是获客闸门。
