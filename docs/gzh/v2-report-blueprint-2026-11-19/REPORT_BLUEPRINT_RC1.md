## 一、基礎定位與讀者承諾

**1320 是以生日計算之象徵性自我反思工具，不是人格科學測驗、命運預測、靈性等級、診斷或決策權威。**

每一碼採同一敘事順序：
1. **完整定義**：這一碼是什麼、象徵什麼；不使用假定讀者經歷的斷言。
2. **作用與目的**：它在該模組中處理什麼問題，與其他碼如何分工。
3. **可探索的力量**：以「可能」「供比對」呈現。
4. **內在張力與保護模式**：描述風險，不責怪、不診斷。
5. **至少兩個日常假設情境**：明確標示「假設案例」，覆蓋工作／關係／日常等場合；不冒充實際個案。
6. **可能帶走的領悟**：不做宿命裁判。
7. **讀者反思問題**：一至兩題，保留讀者不認同或跳過的權利。
8. **來源與安全**：內部追溯到原始原型資料，對顧客僅顯示必要的非專業性聲明。

可讀性原則：清楚而深刻；同一個生日的不同模組不得複製貼上相同段落；不同生日不得套用前一生日的私人生活敘事。

## 二、Sample Report（當前 v2 保護 Preview）

**目的：** 讓讀者完整理解四個象徵視角如何連在一起，而不是付費版的殘缺摘要。

**固定閱讀順序：S1 → S3 → S2 → S0 → 四碼整合**。這是本輪確立的 v2 Sample 規格。每份 Sample 提供：

| 區塊 | 作用 | 輸出要求 |
|---|---|---|
| 封面與使用說明 | 確認生日、象徵性聲明、非診斷性質 | 不含靈性等級評級 |
| 四碼總覽 | 在進入敘事前辨認 4 個 Code、正式候選名稱 | 清楚對照 Code，不稱算式為科學證明 |
| 01：S1 靈魂本源 | 一個原型的定義、核心意義、力量與張力 | 完整定義先行 |
| 02：S3 靈魂振動 | 同一個原型如何探索、表達與學習 | 不是更高或更低的靈性層級 |
| 03：S2 靈魂鏡像 | 關係／互動中可被觀察的現象 | 鎖定 S2 安全句；不鼓勵忍受傷害 |
| 04：S0 空性之門 | 可能需要重新檢視的信念 | 不診斷、不怪罪 |
| 05：四碼整合 | 至少 2 條「S1→S3→S2→S0」有辨識度的跨碼連結 | 不必同意全部；不能偷渡 S4 解讀 |
| 06：讀者反思 | 2–3 個日常可驗證問題 | 不引導焦慮式付費轉換 |
| 07：收束 | 尊重讀者主權，提供足夠的完整感 | 不使用恐懼行銷 |

**Sample 的體驗完成條件：** 讀者能說出每碼的不同意義、讀到至少一個可檢驗的生活場景、理解四碼共同主題，並保有自己的判斷；不會因未購買 Full 而留下「不完整／危險」暗示。
