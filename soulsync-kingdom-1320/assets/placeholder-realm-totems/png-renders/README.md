## 与 Visual UI Handoff 独立 SVG 文件的对照（2026-10-18）

- 四个 SVG 文件的路径与圆的几何数据，与游戏内联 SVG **逐项一致**（已用脚本比对）。
- 差异只有两处：① 独立 SVG 把镜面轴、基准线、外环画成**实线**，游戏内联版画成**细虚线**；② 独立 SVG 没有圆形光晕。
- 文案：S3 实际是「两道弧线 + 中心点」。独立 SVG 的描述写「双重弧线」，数据包表格写「三重弧线」，建议统一为「两道弧线与中心点」。
- 独立 SVG 内部使用固定的 `id="title"` / `id="desc"`：若将来把它们直接内联进同一页面会产生重复 ID，应改成按境区分的 ID。
