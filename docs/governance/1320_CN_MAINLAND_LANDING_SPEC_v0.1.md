# 1320 CN Mainland Landing Spec v0.1

**Status:** Founder LOCK · 2026-09-28  
**Authority:** Founder (Wisewave)  
**Governing principle:** 1320 China is **not** an English website translated into Chinese. It is a **Mainland-ready product architecture** with its own public-language layer, data architecture, compliance gates, and distribution model — while preserving the underlying 1320 system.

**Supersedes as governing China doc:** any prior “locale /zh/ only” framing.  
**Demotes to component:** global Simplified Chinese localization (`/zh/`) is **CN-0A** scaffolding — **not** Mainland Public Launch.

---

## Founder model (summary)

```
One Mainland-ready foundation
→ two primary domestic entry points
→ three layers of language governance
→ four staged rollout phases
```

**Practical stack:**

- Mainland-ready infrastructure  
- WeChat Mini Program + compliant H5 entry  
- Public name: **1320｜生命映照**  
- Deterministic rules + reviewed templates (CN-0 generation)  
- Minimum-data / local-first architecture  
- CN semantic review as content gate  
- Free before Paid  
- Compliance before growth  

**Must not present as:** fortune-telling, divination, destiny prediction, psychological diagnosis, or therapeutic treatment.

## 8 · Three-Layer CN Language Governance

Every Mainland-facing string must pass:

1. **Meaning Parity** — Chinese must not claim stronger than governed English (no possibility→certainty, pattern→causation, reflection→identity, symbol→fact, interpretation→prediction).  
2. **Mainland Public Semantics** — reject 命理化, 玄学确定性, 封建迷信式表达, 财富/婚姻预测, spiritual hierarchy, therapeutic/diagnosis language, metaphysics as verified fact.  
3. **Brand Voice** — still quiet, spacious, reflective, user-authority preserving (compliance without sounding bureaucratic is not enough).

## 14 · Data Architecture — FOUNDING PRINCIPLE

Prefer:

- minimum collection  
- local-first processing  
- Mainland-isolated storage where user data must be stored  
- **no default** return of Mainland user personal data into the global product stack  

Free experience: birth-date calculation **locally where technically practical**. If no account/storage needed, do not collect extra “because we can.”

**Do not collect by default:** birth time · birthplace · precise location · religion · health/psych diagnosis · financial info · ID documents  

“No cross-border transfer” = **preferred architecture**, not a claim that every transfer is legally forbidden. Future need → open **China Data Export Review** before implementation.

## 20 · Rollout Stages

### Phase 0 — Naming & Compliance Pre-Review

Before Mainland build lock: trademark · product naming · Mini Program name · category pre-review · operating-entity plan · legal/compliance · advertising-language review.

### CN-0A — Simplified Chinese Experience (AUTHORIZED for Nova)

Global-site localization layer. Nova may build:

- `/zh/` routing · language switcher · zh-CN resolution  
- Chinese nav / footer  
- Chinese Free journey · Chinese result shell  
- canonical / hreflang  
- translation-completeness checks  
- deterministic result assembly  
- CN semantic-review gates (process hooks)  

**Not** a Mainland marketing launch.

### Mainland Readiness Gate (must pass explicitly)

Before public promotion in Mainland: terminology · category positioning · legal copy · privacy · data architecture · cross-border · deployment · platform category · support · payments · commercial claims · moderation · complaint/reporting.

### CN-1 — Mainland Free Public Experience

Compliant H5 · Mini Program · WeChat service entry · Chinese support · complaint flow · moderation · Free 生命映照.  

Goal: users understand the product correctly and complete meaningful reflection safely.

### CN-2 — Paid Product

Only after CN-1 evidence + compliance: Chinese Full Report · payments · invoices · refunds · CS · commercial claim governance · licensing as required.

### CN-3 — Growth

Only after category is stable: content series · articles/video/podcast · creators · independent CN SEO · paid acquisition if appropriate.  

**先建立类别，再建立流量。**
