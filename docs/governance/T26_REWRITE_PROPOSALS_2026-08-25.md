# T26 rewrite proposals — 2026-08-25

Status: **proposal for 玄微 language acceptance**. Live copy is unchanged until these sentences are accepted.

Principle: **Preserve the symbol. Remove the unsupported ontological claim.**

`original pattern` / `awakening` / `Soul Mission` / `beneath adaptation` stay. Grammar must not imply 1320 has proven these things exist independently of the symbolic reading.

Evidence layers used below:

| Layer | Meaning |
|---|---|
| Calculation | What the system computes from a declared method |
| Tradition | Named symbolic vocabulary 1320 uses |
| Resonance | Invitation to notice / reflect |
| Evidence | Empirical claim that could be true or false in the world |
| Authority | Instruction, verdict, or ranking over the reader |

A sentence closes only if all three questions pass. Question 3 is the easy miss.

---

## 1. FAQ · S1 · Soul Origin

**Surface:** `/faq` · `lib/faq-content.ts` · “What is S1 · Soul Origin?”

**Current:**
> Your Soul Origin points to the original pattern beneath adaptation — gifts, shadows, and direction that remain when roles fall away.

**Proposed:**
> In 1320, S1 · Soul Origin is used as a symbolic mirror for exploring the original pattern beneath adaptation — gifts, shadows, and direction that may feel more present when roles fall away.

### Three questions

1. **Layer?** Tradition + Resonance. The names S1 and original pattern are 1320’s symbolic vocabulary; “exploring / may feel” is an invitation, not a finding.
2. **Did grammar raise the layer?** Current “points to … that remain” treats the pattern as an existent remainder 1320 has located. Proposed “is used as a symbolic mirror for exploring … that may feel” keeps the same symbols one layer down. Not Evidence, not Authority.
3. **Naive reader?** Unlikely to hear “science has shown your original self.” More likely: “this is how 1320 invites you to look.” Pass.

## 2. Page 01 · foundation summary (P1)

**Surface:** `/what-is-a-soul-blueprint` · `PAGE01` summary line 1 · `lib/seo/content/what-is-a-soul-blueprint-body.ts`

**Current:**
> Who you are beneath adaptation.

**Proposed:**
> S1 is used in 1320 as a symbolic mirror for exploring what may feel more foundational, or less shaped by later adaptation.

### Three questions

1. **Layer?** Tradition + Resonance. Same symbol (`beneath adaptation`); framed as 1320’s use of S1, not as a description of the person.
2. **Did grammar raise the layer?** Current copula “who you are” is an identity statement (Authority / Evidence). Proposed “may feel more foundational” is Resonance. The example direction from the work order is followed, not copied as a slogan elsewhere.
3. **Naive reader?** Current line is the easy miss: a stranger reads it as fact about who they are. Proposed line attributes the move to 1320 and hedges with “may feel.” Pass.

## 3. FAQ · S0 · Void Gate

**Surface:** `/faq` · `lib/faq-content.ts` · “What is S0 · Void Gate?”

**Current:**
> Your Void Gate shows how you meet uncertainty and return to self. It is an awakening gate for reflection — not fate, collapse, or diagnosis.

**Proposed:**
> In 1320, S0 · Void Gate is used as a symbolic mirror for how you meet uncertainty and return to self. 1320 calls this an awakening gate for reflection — not fate, collapse, diagnosis, or a claim that an awakening has occurred.

### Three questions

1. **Layer?** Tradition + Resonance. `awakening gate` is kept as 1320’s name for the mirror, not as an event that happened to the reader.
2. **Did grammar raise the layer?** Current “It is an awakening gate” predicates being. Proposed “1320 calls this an awakening gate” is naming. The existing “not fate / collapse / diagnosis” boundary is kept and extended so awakening itself is not smuggled back in as a fact.
3. **Naive reader?** Could still hear “my void is an awakening.” The second sentence now says 1320 *calls* it that, and denies that an awakening is being asserted. Pass.

## 4. Page 01 · S5 · Soul Mission

**Surface:** `/what-is-a-soul-blueprint` · `PAGE01_FULL_MAP` S5 body · `lib/seo/content/what-is-a-soul-blueprint-body.ts`

Title **Soul Mission** is the symbol and stays.

**Current:**
> The deeper direction of meaning, contribution, and purposeful expression.

**Proposed:**
> In 1320, S5 · Soul Mission is a symbolic layer for exploring direction of meaning, contribution, and purposeful expression — not a verified vocation, ranking, or destiny.

### Three questions

1. **Layer?** Tradition + Resonance. Soul Mission remains a named layer. “Exploring direction” is invitation. The trailing clause blocks Evidence (“verified vocation”) and Authority (“destiny”).
2. **Did grammar raise the layer?** Current definite “the deeper direction” presents a real telos 1320 has identified. Proposed “a symbolic layer for exploring” does not.
3. **Naive reader?** “Soul Mission” as a heading still sounds like a fact. The body now says it is a 1320 layer for exploring, and names what it is not. Pass — *if* the heading is not reused later as “your mission is X” without the same hedge. That later misuse is C-4 question 4 (reflection → identity), not this sentence.
